## Handsout v1.0.0

菜单栏常驻的 macOS 快捷键启动器：给常用应用绑上 `⌥+字母/数字`，长按 `⌥` 看一眼全部快捷键，再按一次把应用收回去。

### 功能

- `⌥+字母/数字` 一键唤起应用，已运行则切到已有实例
- 长按 `⌥` 弹出面板（图标 + 名称 + 快捷键角标），继续按键或点击启动，松手关闭
- 再按一次隐藏应用，并自动切回上一个在用的应用
- Finder 这类「关掉窗口但进程还在」的应用也能正确打开
- 自动按应用名首字母分配快捷键，支持录制改键，冲突自动接管
- 开机启动开关、长按延迟可调

### 安装

1. 下载下方 `Handsout-v1.0.0.zip` 并解压
2. 把 `Handsout.app` 拖到 `/Applications`，双击运行
3. 菜单栏出现双手图标，进入设置添加应用与快捷键

首次使用需要在「系统设置 → 隐私与安全性 → 辅助功能」里勾选 Handsout —— **长按 ⌥ 弹面板需要这个权限**，`⌥+字母` 直接启动不需要。

> 当前为 ad-hoc 签名，首次打开可能被 Gatekeeper 拦截：右键 →「打开」，或在「隐私与安全性」中点「仍要打开」。

### 要求

macOS 13 及以上（arm64 / x86_64）
